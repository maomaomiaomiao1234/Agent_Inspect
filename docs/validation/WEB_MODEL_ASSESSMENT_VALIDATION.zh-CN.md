# 网页真实模型评测入口验收

日期：2026-10-05。

## 使用流程

1. 安装 Git 并启动 Docker；在项目根目录配置 `.env`，变量格式参考 `.env.example`。
2. 运行 `uv run agent-review serve`，打开 `http://127.0.0.1:8765` 的仓库评测页面。
3. 填写 `https://github.com/huggingface/smolagents`，按需调整参数并启动。服务固定源码版本、构建目标、注入模型配置、执行题集、保存证据并清理容器。

模型配置优先读取专用 `AGENT_REVIEW_TARGET_*`，否则选择带密钥的 `SMOL_MODEL_*`，再选择带密钥的 `AGENT_REVIEW_LLM_*`。地址、模型和密钥来自同一组；已有完整评审配置可以直接复用。修改 `.env` 后须重启服务。缺配置或格式无效时网页显示原因，真实评测不会自动变为离线。

网页参数包括案例数、种子、源码版本、模式、期限、输出 Token 上限、重复次数、并发和生成策略；固定上传题集沿用题集参数。服务端提供默认值，网页可覆盖。默认累计期限上限 900 秒，记忆等多轮案例仍按顺序执行。

|检查|结果|

|后端全量测试|383 passed、2 skipped、2 warnings|
|Chrome 浏览器测试|9 passed：仓库入口、参数修改、缺配置阻止提交、显式离线、主动评测、Token 展示|
|环境配置测试|使用临时假配置，验证自动加载、进程环境优先、禁止变量插值、按组选择及缺字段提示|
|评测管线测试|模拟构建和目标调用，验证真实模式解析、默认配置注入、源码规划参数及导出一致|
|凭据处理测试|能力接口、任务记录、构建上下文和导出不含测试密钥；仅映射允许的变量名|
|静态与构建|Ruff、git diff --check、TypeScript/Vite、wheel 和 Skill 同步|

两个跳过和两条弃用警告来自现有可选依赖与 Starlette/httpx/AnyIO 兼容检查。本轮没有读取、修改或上传用户本地 `.env`，没有新增付费供应商调用，也没有重新执行真实 Git/Docker 仓库构建。因此这些结果验证配置与执行管线，不证明当前配置的模型可访问或任意仓库能自动部署。

## 当前边界

此轮验收时固定自动部署配方只有 smolagents。后续已实现 [Python LLM 自动适配](../guides/AUTO_ADAPTATION.zh-CN.md)，未知 Python 仓库可生成清单与桥接入口后实际验证；不能保证任意仓库成功。人工清单仍可使用，非标准变量需服务端许可。Token 和工具记录依赖目标真实上报，缺失证据仍显示未知或已观测下界。API 密钥只在服务端读取并传入运行容器，不传到网页，不注入构建。

详细配置见 [仓库评测指南](../guides/REPOSITORY_ASSESSMENT.zh-CN.md)。
