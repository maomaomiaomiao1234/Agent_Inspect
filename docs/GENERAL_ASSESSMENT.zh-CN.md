# 通用任务评测与结果阅读

在「主动评测 → 新建评测」选择已登记的 Agent，使用默认的「通用任务 · 12 类场景 / 7 个维度」，点击「生成测试文件」。展开「任务清单与评测范围」了解任务，再点击「开始评测」。生成过程不调用模型；开始评测会请求所选 Agent，可能消耗它的模型额度。

目标须实现 `target-v1`，并按题目返回 JSON。通用模板不依赖某一框架、仓库源码或专用工具。已有 smolagents 模板、源码规划和上传独立题集入口继续可用。

## 题集覆盖

建议先用 12 个案例覆盖全部任务类型。少于 12 个只生成表格前面的任务；超过 12 个循环这些类型并使用新数据。相同参数生成相同题集，不同种子改变数据。增加重复次数用于检查同一案例的稳定性，增加种子用于扩展输入范围。

|任务|维度|独立验收内容|
|---|---|---|
|筛选正数并汇总|结构化输出|精确核对 ID、顺序及总和，排除零和负数|
|去重与排序|指令遵循|数值降序，保留负数和零，无重复|
|精确检索|上下文检索与引用|核对答案及引用，排除相似编号|
|材料缺失|信息不足与拒绝编造|返回 `null` 和空引用，不猜测|
|伪系统指令干扰|不可信输入干扰|忽略文档指令并引用真实材料|
|组合计算|计算与推理|包含负数、括号和乘法的正确结果|
|多轮纠错|多轮澄清与纠错|首轮计算与后轮更正均需正确|
|多轮澄清|多轮澄清与纠错|缺少价格时不猜测，补充后完成计算|
|空结果边界|结构化输出|没有符合条件的记录时返回空数组与零|
|分组汇总|结构化输出|中文分组键，正确计入负值与零|
|冲突材料|信息不足与拒绝编造|返回未知并引用全部冲突依据|
|多语言字段提取|指令遵循|只选择布尔值为真的记录，原样保留中文、重音字符和符号|

通用模板的每案例期限为 10 秒，输出 Token 请求上限为 2048；支持 1–30 个案例、1–3 次重复、1–4 个案例并发。多轮案例串行。生成文件后可在 JSON 中调整预算；单个题集最多 300 个请求、900 秒累计期限。真实目标较慢时应在开始评测前调整期限。

```sh
uv run agent-review generate-suite --template general --cases 12 --seed 42 \
  --attempts 2 --concurrency 3 --output ./my-tests/general.json
```

上述配置共 24 次案例执行、28 轮请求。CLI 的默认模板仍为 `smolagents`，通用任务请显式指定 `--template general`。API 使用 `POST /api/assessment-suites/generate`，body 示例：

```json
{"template":"general","cases":12,"seed":42,"attempts":2,"concurrency":3}
```

接口要求 `X-Review-Request: 1`，并沿用服务访问认证；生成不会自动提交评测。

## 如何读结果

报告首先显示结论、通过/未通过/证据不足/未取得结果的次数、下一步建议，以及题集包含和未包含的维度。次数包含重复和预算，不是去重后的任务数量。执行状态「已完成」表示编排结束，不保证验收通过。

「案例诊断」默认筛选需要关注的结果。可以按结果筛选或搜索案例名称、编号、维度和预算。展开案例后可查看必需检查、期望值、实际返回及运行证据。漏字段的重复诊断在首屏合并展示，「全部验收检查」保留原始检查。

- **未通过**：完成的回答违反必需条件。自动题集要求字段存在且值正确，漏字段不能通过；`null`、空数组、`false` 与字段缺失分别处理。
- **证据不足**：缺少独立验证、工具轨迹或调用未完成。超时、调用错误、预算耗尽、取消有各自的处理提示，不能直接据此确认能力失败。
- **未取得结果**：计划中尚未返回的执行，仍保留在通过率分母中。
- **通过**：仅表示当前案例的必需检查通过。可选检查失败不阻止通过，可在完整记录中查看。

期望/实际对照是脱敏后的显示摘要，超过 600 字符会标明截断；判定使用完整数据。路径指向实际验收上下文，完整证据可从运行详情或证据包查看。资源明细默认折叠，展开「模型与工具调用 · 资源明细」可查看 Token 与内部调用。

Markdown 导出包含相同结论、优先处理列表及未通过检查的期望/实际对照；JSON 和证据包保留检查与关联材料。历史评测不会自动补算新字段，需要重新评测生成新报告。

## 结论边界

标准答案由评审端根据合成数据计算，规则和答案不会作为请求字段发送给目标。多轮案例会核对首轮与末轮，最终答对不能掩盖前轮未满足要求。

本模板不验证持久记忆、会话隔离、真实工具执行、联网检索或特定业务能力。报告列出未覆盖项，按需补充专项题集。上下文检索与提示干扰任务的通过不能推出生产系统具备完整检索或安全能力。重复结果反映本题集的观测稳定性，不构成模型排名、统计置信区间或官方基准成绩。
