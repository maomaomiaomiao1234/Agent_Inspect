# 调研任务模板

此模板是合成示例。内置规则只检查摘要长度、来源列表和资源阈值；这些条件不证明事实正确。

`facts` 是一个必需的 `external` 规则。未提供专项评估器结果时，整体保持 `inconclusive`。可以通过 `evaluator-request` 接口把可见材料交给自己的事实核验程序或人工复核流程，然后按响应协议提交有证据的结果。

将自己的工具调用映射到通用事件：`effect: read` 仅用于确实只读的操作，未知副作用使用 `unknown`。`coverage: complete` 是导出器对该任务全部调用的声明；日志不完整时使用 `partial`。
